# Aim Trainer & Vision AI Bot | مدرب التصويب الذكي مع بوت الرؤية الحاسوبية

مشروع تفاعلي متقدم لتدريب واختبار سرعة ودقة التصويب (Aim Training)، مزود ببوت تصويب مغلق الدائرة (Closed-loop Vision Bot) يعتمد بالكامل على قراءة الشاشة فقط (بدون أي حقن للذاكرة)، ومدعوم **بنموذج ذكاء اصطناعي مساعد (AI Assistant Model)** لرفع الكفاءة والدقة والسرعة لأعلى مستوى.

---

## 🌟 مميزات المشروع والنموذج المساعد (AI Assistant)

1. **النموذج البصري الذكي (`SmartTargetDetector`)**:
   - كشف فائق الدقة لأهداف التصويب مع حساب العزوم تحت البيكسل (Sub-pixel accuracy).
   - خوارزمية ذكية لمعالجة وتجاوز حجب المؤشر (`Occlusion Recovery`) باستخدام الـ Convex Hull والتقريب المورفولوجي عند مرور المؤشر فوق الهدف.
   - مقياس جودة وتطابق هندسي ودائري (`Circularity & Confidence Scoring`).

2. **نموذج التنبؤ الحركي وتعويض زمن الاستجابة (`PredictiveAimModel`)**:
   - تعويض تأخير خط أنابيب المعالجة والالتقاط (Latency Compensation ~25ms).
   - التنبؤ بمسار وموقع الهدف القادم لتفادي تأخر البوت (Lead Targeting).
   - تخطيط المسار الحركي المثالي الخالي من الارتداد (`Minimum-Jerk Trajectory Planning`) لإلغاء أي تجاوز للمؤشر (Overshoot) وتسريع زمن الوصول للهدف.

3. **المدرب الذكي ومحسن الإعدادات التلقائي (`AIPerformanceCoach`)**:
   - تقييم فوري لجلسات التصويب (نقاط الكفاءة من 100).
   - تحليل توزيع زمن رد الفعل (Reaction Time Percentiles: Mean, Median, P95).
   - اقتراح وضبط المعلمات تلقائياً (`aim_speed`, `smoothing`, `deadzone`) للوصول لأعلى معدل إصابة في أقل وقت.

4. **معمارية متعددة الخيوط عالية الأداء (`BotWorker`)**:
   - فصل حلقة الرؤية والبوت في مسار منفصل (`Background Worker Thread`) يعمل بتردد 30-60 Hz مع الحفاظ على معدل إطارات ثابت 60 FPS لواجهة المستخدم.
   - دعم شامل لشاشات العرض الحديثة وتوافق DPI (`Per-Monitor DPI Awareness`).
   - مفتاح أمان الطوارئ الفوري بمجرد تحريك الماوس إلى زاوية الشاشة (`Virtual Screen Corner Fail-Safe`).

## 🚀 طريقة التشغيل المباشرة كتطبيق مستقل (One-Click App)

لا تحتاج إلى فتح شاشة الأوامر (Terminal) أو بيئة افتراضية، يمكنك تشغيل التطبيق والعمل به مباشرة:

1. **التشغيل المباشر بالنقر المزدوج (Double-Click)**:
   - افتح المجلد واضغط مرتين على ملف **`AimBot.vbs`** (أو **`Start_AimBot.bat`**).
   - سيفتح التطبيق فوراً كنافذة ويندوز رسومية مستقلة بدون أي شاشة أوامر سوداء.

2. **إنشاء اختصار مباشر على سطح المكتب (Desktop Shortcut)**:
   - اضغط مرتين على ملف **`Create_Desktop_Shortcut.bat`**.
   - سيتم إنشاء اختصار جاهز باسم **Aim Bot AI** على سطح مكتبك لتفتحه في أي وقت بضغطة زر.

3. **طريقة العمل العادي مع ألعابك أو متصفحك (Desktop Mode)**:
   - افتح التطبيق، واضغط زر **⚡ تشغيل البوت (ON)** أو اضغط مفتاح **`F6`**.
   - اذهب إلى أي لعبة أو موقع تدريب تصويب (مثل Aim Lab، Human Benchmark، أو متصفحك) والعب بشكل طبيعي:
     - البوت سيرصد الأهداف الحمراء/الملونة ويلتقطها فوراً بنعومة وسرعة فائقة.
     - يمكنك في أي لحظة الضغط على **`F6`** للإيقاف المؤقت أو إعادة التفعيل.
     - **أمان الطوارئ**: حرّك الماوس لأي زاوية من زوايا الشاشة وسيتوقف البوت فوراً تلقائياً.

## 🛠️ أوضاع التشغيل للمطورين (Developer Options)

لتشغيل نافذة التدريب المدمجة عبر سطر الأوامر:
```powershell
python main.py
```
أو تشغيل لوحة التحكم الرسومية المستقلة:
```powershell
python desktop_app.py
```

لتشغيل حزمة الاختبارات الشاملة:
```powershell
python -m pytest
```

## ⌨️ اختصارات لوحة المفاتيح (Keybindings)

| الزر | الوظيفة |
| :--- | :--- |
| **`Space`** | بدء الجلسة / إعادة البدء بعد انتهاء الوقت |
| **`B`** | تشغيل / إيقاف بوت التصويب الآلي (Bot ON/OFF) |
| **`M`** | تفعيل / تعطيل النموذج المساعد الذكي (AI Assistant ON/OFF) |
| **`D`** | تشغيل / إيقاف شاشة التشخيص والرؤية الحاسوبية (Debug View) |
| **`R`** | إعادة ضبط الجلسة فوراً (Restart) |
| **`Esc`** | حفظ الإعدادات والخروج بأمان |

## 📁 هيكلية المشروع (Project Architecture)

```
aim_trainer_project/
├── main.py                 # نقطة الدخول الرئيسية وحلقة اللعبة
├── config.py               # الإعدادات وثوابت الشاشة والتحكم
├── requirements.txt        # مكتبات بايثون المطلوبة
├── pytest.ini              # إعدادات الاختبارات
├── README.md               # دليل التشغيل والتوثيق
├── bot/
│   ├── assistant.py        # النموذج المساعد الذكي (Detector + Predictor + Coach)
│   ├── worker.py           # مدير مسار عمل البوت في الخلفية (Multithreaded)
│   ├── capture.py          # التقاط الشاشة فائق السرعة عبر MSS و WinAPI
│   ├── vision.py           # محرك معالجة الصور عبر OpenCV
│   └── controller.py       # التحكم الحركي المغلق بالماوس عبر PyAutoGUI
├── core/
│   ├── game.py             # منطق الجلسة، توليد الأهداف واحتساب النقاط
│   └── ui.py               # واجهة المستخدم ولوحة التحكم الرسومية عبر Pygame
└── tests/
    ├── test_assistant.py   # اختبارات النموذج المساعد الذكي
    ├── test_worker.py      # اختبارات مسار البوت
    ├── test_config.py      # اختبارات ملف الإعدادات
    ├── test_game.py        # اختبارات منطق اللعبة
    ├── test_vision.py      # اختبارات كشف الأهداف
    ├── test_controller.py  # اختبارات التحكم بالماوس
    └── test_capture.py     # اختبارات التقاط الشاشة
```
